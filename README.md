# Student Performance Analytics Portal (SPAP)

## Project Description

The Student Performance Analytics Portal (SPAP) is a web-based application developed using HTML, CSS, and JavaScript. It helps manage student records, monitor academic performance, and generate reports through an interactive dashboard.

## Features

- Student Login System
- Student Dashboard
- Student Records Management
- Search Students
- Sort Students
- Department Filter
- Pass/Fail Status
- Student Performance Chart
- Pagination
- Export CSV
- Export PDF
- Print Report
- Dark Mode
- Notification Panel
- Responsive Design
- Form Validation
