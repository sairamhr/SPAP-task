# Student Performance Analytics Portal (SPAP)

## Project Overview

Student Performance Analytics Portal (SPAP) is a front-end web application designed to organize, manage, and analyze student academic performance data through an easy-to-use dashboard.

The system provides a user-friendly interface for viewing student records, analyzing marks, checking performance statistics, and generating reports.

## Features

- Student Registration
- User Login
- Dashboard
- Student Performance Records
- Marks Analysis
- Pass/Fail Statistics
- Average Marks
- Sorting Functionality
- Charts and Data Visualization
- Performance Reports
- Form Validation
- Responsive Design
- User-Friendly Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- Visual Studio Code
- GitHub

## Installation Steps

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the project using Live Server.
4. Open the `index.html` file.
5. Navigate through the application using the navigation menu.
